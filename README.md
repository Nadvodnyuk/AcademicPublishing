# AcademicPublishing

Информационная система управления научными публикациями предназначена для автоматизации процесса подачи, хранения, обработки и анализа научных работ. Система позволяет неавторизованным пользователям (авторам) отправлять статьи, а авторизованным пользователям (организаторам, рецензентам) — просматривать, редактировать и управлять статьями и данными об авторах, а также отслеживать публикационную активность на основе визуализации данных.

## Стек

**Backend**  
  - Python
  - FastAPI
  - Tortoise ORM + Aerich
  - Pydantic
  - OAuth2 + JWT
  - PostgreSQL (БД)

**Frontend**  
  - Vue.js
  - Vue Router
  - Vuex
  - Bootstrap
  - Axios

## Требования к окружению

- Python 3.9 или выше (до 3.12)
- Node.js 14+
- PostgreSQL

## Сборка
- **Backend**
   ```sh
   cd backend
   Py -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
   Настройка и применение миграций

   ```sh
   aerich init -t src.database.config.TORTOISE_ORM
   aerich migrate
   aerich init-db
   aerich upgrade
   ```
   Запуск приложения
   ```sh
   uvicorn src.main:app --reload --host 0.0.0.0 --port 5000
   ```

- **Frontend**
    ```sh
    cd frontend
    npm install
    npm run build
    npm run serve
    ```

## Основные страницы для неавторизированных пользователей

**Создать статью**
  - Форма для отправки статьи:
    - Сведения об авторах ("ФИО", "Код научного автора" и тд.). Можно добавлять авторов, всего может быть 4.
    - Сведения о работе ("УДК", "Название научной работы", разделы и тд.)


**Страница входа**
  - Войти в аккаунт могут только пользователи (преподаватели, организаторы), которым предоставлен доступ. Создать нового пользователя можно только путем добавления его в БД SQL запросами.
  - После входа автор остается авторизированным один час


## Основные страницы для авторизированных пользователей
**Все статьи**
  - Список всех статей в виде карточек с названием, авторами, и ссылкой на просмотр статьи
  - Поиск по статьям
  - Фильтрация по годам и УДК
  - Сортировка по году и названию

**Страница статьи**
  - Представлены авторы и текст статьи. Можно перейти на страну автора.
  - Можно скачать pdf статьи и удалить статью
  - Также можно редактировать статус статьи

**Редактирование статьи**
  - Выбор статуса из списка (рецензирование, редактирование, плагиат, препринт и тд.)
  - При изменении статуса авторам статьи будет автоматически отправлено электроннои письмо об изменении статуса данной статьи для отслеживания

**Все авторы**  
  - Список всех авторов в виде карточек с именем и ссылкой на просмотр страницы автора
  - Поиск по авторам
  - Сортировка по имени

**Страница автора**
  - На странице автора указана вся информация о нем (из формы для отправки статьи)
  - Показан список всех статей автора
  - Представлены диаграммы, которые представляют из себя анализ публикационной активности автора:
    - Круговая диаграмма интересов автора (УДК, использованные автором в его статьях)
    - Диаграммы для каждого года, в которых автор писал статьи. Каждая - столбчатая диаграмма с накоплением, отражающая количество статей в различных разделах и их статус. Каждый столбец - одна сфера интересов автора, а подкатегории в этом столбце - статус работ с таким УДК.
  - Можно удалить автора

**Аккаунт**
  - Представлена информация о пользователе
  - Можно удалить аккаунт
